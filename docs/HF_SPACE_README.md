# Taglish-RAG

Ask a question about **BIR**, **PhilHealth**, or **Pag-IBIG** in English, Tagalog, or Taglish, and get an answer grounded in retrieved government source documents (with citations).

Full project writeup, retrieval ablations, and evaluation methodology: [github.com/Jaelih/taglish-rag](https://github.com/Jaelih/taglish-rag).
